# 角色持续丰满机制（活档案 · 只增不减）

> 定位：让每个角色随章节"内容越来越多、越来越真"。角色库不是一次写死的人设卡，是**随写随长的活档案**。解决"前期人物鲜、后期扁平"和"新章忘检测旧人设"两病。
> 一句话哲学：故事越写越真、剧情越连越紧，靠的是档案只增不减地长大——每个角色的内容不断延伸，新章必回头检测旧人设。

---

## 铁律

- 角色库文档**只增不减**：新角色出场即入卡；已有角色每章展现新侧面 → 追加入「成长记录」区，**原设定红线永不打覆写**。
- 红线 immutable：忌讳 / 说话方式底线是硬约束。新增只可**收紧**（加新忌讳）不可**放宽**（删旧忌讳），除非用户明确改设定。
- 每章开工前（Hook 3 翻文档）列出本章出场角色 → 逐个 `grep` 角色卡 → 对照「说话方式示例 + 忌讳 + 当前关系网」写台词，**越界即退**。
- 每章成稿后回写：把本章产生的角色新信息追加（新关系 / 新实力刻度 / 新忌讳 / 声线微调 / 暗线推进 / 情绪底色变化）。
- 关系网生长：角色卡含「关系网」字段，新羁绊（敌 / 友 / 暧昧 / 师徒 / 上下级）出现即追加，人物从孤立点长成网。
- 档案规模随字数线性生长是**健康信号**，不是负担——角色越厚，故事越真。

## 角色卡结构（永不动区 + 成长区）

```
【姓名】身份/阵营/所属血脉序列
【性格】≤12字 + 一句话底色
【说话方式示例】带情绪/动作/反应，禁干净白话（immutable 底线）
【动机】他要什么（最终如何影响结局）
【忌讳(immutable)】绝不能说的话/做的事（红线，只增不减）
【暗线】该人物自己的人生线（目标≠主角）、与主线交汇点、揭晓方式
【关系网】敌/友/暧昧/师徒…（随章追加）

---- 以下为成长记录区（按章追加，不覆写上方）----
【成长记录】
- 第X章：新增[关系/实力/忌讳/声线/暗线] —— 具体表现（一句锚点）
- 第Y章：……
```

## 调用协议

1. **开工**：列出出场角色 → `grep 角色库` → 取「说话方式 + 忌讳 + 当前关系网」→ 写台词。
2. **成稿**：扫本章角色新信息 → 追加入该卡「成长记录」→ 新关系进「关系网」→ 存盘。
3. **门禁**：Hook 12 第 1 项对角色库核对；本章若有角色行为突破，必须在「成长记录」留痕，否则视为档案未维护（不阻断，但记入章末自检）。

## 与根基文档咬合

- 角色库 ⊇ 边界卡（Hook 3）。本机制让边界卡从"静态红线"长成"带成长履历的活边界"——既锁死 OOC，又允许人物自然生长。
- 暗线（`plot-threads.md`）/ 多线（`thread-weave.md`）的进展，落到角色卡「暗线 + 关系网」字段，逐章回写即逐章推进暗线 → 伏笔台账（`foreshadow-ledger.md`）随之推进 → 三者咬合，故事越写越有分量。
