# 爽点工程（cool-points）

> 解决「有剧情但不够爽、读者不爽、弃书」的问题。
> 思路借鉴自 webnovel-writer 的 cool-points-guide，重写为夜秣语境。
> 配合 `knowledge/爽点与节奏.csv`、`knowledge/桥段套路.csv` 使用。

<methods>

## 一、六种爽点执行模式

| 模式 | 结构 | 适用 |
|------|------|------|
| 装逼打脸 | 对方轻视 → 主角展示实力 → 对方震惊/后悔 | 都市/玄幻/职场 |
| 扮猪吃虎 | 表面弱小 → 关键时刻爆发 → 众人惊艳 | 重生/隐藏身份 |
| 越级反杀 | 实力差距明显 → 主角逆袭 → 敌人不可置信 | 玄幻/武侠/竞技 |
| 打脸权威 | 权威质疑 → 主角用实力证明 → 权威认可/尴尬 | 职场/学院/技术流 |
| 反派翻车 | 反派得意 → 计划破产 → 反派狼狈 | 全部 |
| 甜蜜超预期 | 平淡日常 → 意外惊喜 → 情感升温 | 言情/甜宠 |

## 二、爽点三段式（30/40/30 参考框架）

- **铺垫 30%**：建立预期、制造反差、设信息差（读者知道什么 / 角色知道什么）。
- **兑现 40%**：触发事件、用对话/动作/结果展现、情绪到达高峰。
- **微反转 30%**：假结束 → 还有一手 → 余韵暗示。

> 30/40/30 是诊断参考，不是硬性配比。铺垫太少 → 势能不足 → 爽感虚。

## 三、打脸四步法（核心套路）

1. **铺垫**：提前 1-2 章建立信息差（读者知主角底牌，反派不知）。
2. **挑衅**：1-3 次挑衅建立对照组（反派被捧 vs 主角被踩）。
3. **拉扯**：2-3 轮交锋，主角示弱 → 反派得意 → 期待拉满。
4. **爆发**：物理碾压 + 精神打击 + 围观反应 + 实质收获（战利品/认可/资格，至少补一样）。

## 四、信息差设计

```
读者知主角是隐藏大佬 + 角色不知 = 期待感
角色嘲讽主角 + 读者知主角实力 = 爽感积累
主角展示实力 + 角色震惊 = 爽感释放
```
- 核心层：读者知道但角色不知道的关键信息。
- 反转信息：微反转时揭示的新信息。

## 五、压扬比例（按题材）

| 题材 | 压扬 | 说明 |
|------|------|------|
| 传统爽文 | 压3扬7 | 轻压快放 |
| 硬核正剧 | 压5扬5 | 平衡 |
| 虐恋/黑深残 | 压7扬3 | 长压爆发更爽 |

节奏：`慢铺垫（压）→ 快爆发（扬）→ 停顿 → 再加速`。

## 六、微反转类型

- 还有更强（「你以为这就是我的全力？」）
- 意外收获（打败对手 → 宝物比预期更珍贵）
- 对方更惨（输比赛 → 赌注曝光 → 身败名裂）
- 情感升温（以为普通礼物 → 精心准备 → 落泪）
- 真相揭示（普通玉佩 → 上古神器 → 还认主）

## 七、爽点密度（滚动窗口，预警非硬判）

- 逐章：优先保证有「爽点或同等兑现」，过渡章可低密度，但不允许整章无收获。
- 每 5 章：建议 ≥1 组合爽点（2 种模式叠加）。
- 每 10-15 章：建议 ≥1 里程碑爽点（改变主角地位）。
- 连续 3 章同类型爽点 → 风险预警，优先换类型变体或插感情线调节。

## 八、伏笔三层级

| 层级 | 回收周期 | 示例 |
|------|----------|------|
| 核心 | 50-300章 | 主角身世/终极敌人/金手指来历 |
| 支线 | 30-100章 | 配角动机/神秘物品/师门秘密 |
| 装饰 | 10-30章 | 场景细节/小习惯/路人提及 |

</methods>

<anti_patterns>

- ❌ 无铺垫的突然反转 → ✅ 提前 1-2 章埋信息差
- ❌ 一招秒杀无情绪势能 → ✅ 补 1-2 轮有效拉扯或代价
- ❌ 降智反派 → ✅ 基于已知信息的合理轻视
- ❌ 打完无收获 → ✅ 补战利品/认可/资格至少一项
- ❌ 连续 3 章同爽点 → ✅ 换类型或插感情线

</anti_patterns>
