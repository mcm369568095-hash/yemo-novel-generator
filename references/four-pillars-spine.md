# 根基四文档（写作前必须先立 · 先于一切引擎）

> 定位：**根基四文档定方向，yemo 引擎管落地**。引擎再强，没有立项层也会写出"起点低、章间断、老祖突兀、2人终战、照壁无人懂"的病。本文件规定根基四文档如何作为**前置立项层**运行，以及它在七步循环中的调用点。
> 工作范例（已落地，可照搬结构）：`你的作品目录/示例项目\` 下的 `世界构建_*.md`、`初级大纲_*.md`、`角色库.md`、`写作流程_根基文档法.md`。

---

## 总序：立项先于技法

```
[立项层·根基四文档]                 [技法层·yemo引擎]
根基一  世界观+终极秘密    ─┐
根基二  初纲(五卷弧光)     ─┤→ 产出三文档 → 七步单章循环(消费文档) → 门禁+逻辑读者复查
根基三  角色库             ─┘                         ↑写前翻三文档
根基四  逻辑与读者(每章)   ───────────────────────────┘写后必查
```

**铁律**：未产出根基一/根基二/根基三文档，禁止进入单章生成（Hook 11）。这是与原 yemo 流程最大的区别——原流程"设定锚定"偏轻，根基四文档要求**终极秘密与卷级弧光先成文档**。

---

## 根基一 · 世界观与终极秘密

**产出物**：`世界构建_<书名>.md`

**强制规则（缺一则退）**：
1. 从书名/标题反推世界"根命题"（如"示例命题+血脉"→根命题=血脉为王，但血脉从何而来）。
2. 必须给出**终极秘密**（世界尽头的目标/真相），第一卷埋线、末卷揭晓。对标：盗墓→终极 / 阳神→彼岸 / 永生→永生之门 / 本书→重开源脉本源、超脱血脉稀释之枷。
3. 力量/血脉体系**可溯源**：所有家族、所有敌人，其力量都应从同一源头分化解释（否则"遇到别家血脉从哪来"成黑洞）。
4. 终极秘密须**升华主题**：不只是"变强"，是主角对根命题的超越。

**对接引擎**：在 Hook 1（意图识别）之前先跑根基一；其"根命题/终极秘密/同源分流"直接喂给 Hook 5（故事引擎）与 Hook 8（故事引擎提取）的"读者承诺/最终余味"。

---

## 根基二 · 初级大纲（初纲 · 五卷弧光）

**产出物**：`初级大纲_<书名>.md`

**主角永恒弧光（五段，对应五卷）**：
> 迷茫 → 经历 → 认知 → 行动 → 结果

每卷初纲须写明：核心目标（推进终极秘密的距离）、主角状态、3–5 关键事件（含钩子）、出场新角色（预告入角色库）、卷间逻辑链（上卷因→本卷果）。

**写作铁律**：逐章写作不得脱离弧光阶段。某章写不出"得失顶点"（掉宝/立威/露底牌/新知），说明它不在弧光上，删或并。
**对接引擎**：替代原流程中"模糊的大纲确认"，作为 Hook 7（故事策略确认）/ Hook 10（计划构建）的**强制底稿**——章节计划必须能指回初纲的某一卷/某一弧光段。

## 根基三 · 角色库

**产出物**：`角色库_<书名>.md`

**人设卡模板**（>= yemo 边界卡，且可对照写作）：
```
【姓名】身份/阵营/所属血脉序列
性格：≤12字 + 一句话底色
说话方式：示例句（带情绪/动作/反应，禁干净白话）
动机：他要什么（最终如何影响结局）
对结局影响：±
忌讳：绝不能说的话/做的事（OOC红线）
暗线：该人物自己的人生线（目标≠主角）、与主线交汇点、揭晓方式（呼应 plot-threads.md）
```
**强制规则**：初稿生成的所有角色，不论大小，先入角色库再写作；后续章 `grep` 角色卡核对台词。
**对接引擎**：根基三文档 ⊇ yemo 角色边界卡（Hook 3）。边界卡红线是子集；本库额外提供"说话方式示例"供写作时逐句对照，治"对话木头"。

---

## 根基四 · 逻辑与读者校验（每章必查）

**写前逻辑清单**（开工前对照初纲）：
- [ ] 本章事件是否承接上章（动作接动作，非旁白跳转）
- [ ] 实力/血脉体系是否前后一致（不突然升级）
- [ ] 新设定是否已前文铺垫（不可突兀）
- [ ] 章末是否硬收（禁套路化感慨/升华）

**读者视角检查**（全年龄段可读）：
- [ ] 古词/设定词是否**当众解释**（借角色口或动作一次）
- [ ] 历史衍生内容是否对名字/剧情负责
- [ ] 读者零背景能否读懂本章（无"前情提要"依赖）

**古词/设定词汇表**：随写随积累，置文档末；任一词首次出现必须当众解释一次。
**对接引擎**：并入 Hook 12（硬卡点门禁）第 2 项"一致性/逻辑"与 Hook 13（行文质感校对）的"感官锚点"；并作为写后独立复查项。

## 暗线内容线路（主线 + 人物暗线 · 立项层扩展）

> 根基文档管"写什么"，但故事要丰满成史诗，还需"内容线路纪律"：主角主线之外，为每个关键人物（父/伴侣/朋友/重要反派）建一条"人生暗线"，在主线与暗线**逻辑交汇点**产出小高潮/爆点。完整法则与案例见 `references/plot-threads.md`。

铁律：
- 根基二 初纲每卷须标注"本卷激活/推进哪条暗线、第几章与主线交汇、交汇产出什么小高潮"。
- 根基三 角色卡须含【暗线】字段（见上模板）。
- 暗线人物须有：出身背景 + 与主角相遇的"事件因" + 各自人生目标 + 交汇触发条件；相遇靠事件不靠巧合。
- 暗线揭晓须"早埋锚点"（首提至少提前一章露可见信号，呼应根基四"先铺后亮"）。

## 梯度世界观（垂直维度 · 立项层扩展）

> 根基文档管"写什么"（水平靠暗线织密），但世界还要有"垂直纵深"：势力梯度阶梯（城·豪族 → 大城 → 国家世家/皇族 → 大陆超级势力/隐族 → 飞升序列）。完整法则、预埋纪律与示例作品地脉觉醒根因链见 `references/world-gradient.md`。

铁律：
- 根基一 世界构建须含"势力梯度阶梯"小节；终极秘密须贯穿所有阶层，最高层才是秘密尽头。
- 根基二 每卷初纲须附"梯度揭示表"（active/hinted/shadow 三阶层），保持"上有悬念"。
- 高阶层对主角的影响须"因果降维闭环"到当前层可见事件（如：隐族降临←因地脉觉醒←地脉在第1章玉坠发烫），链不能断。
- 高阶层给主角的帮助须"预埋授权"（父被隐族带走→在隐族学真相→归来带资源），禁天降贵人。
- 每层多生暗线，须用"暗线登记表"（人物×阶层×交汇卷×锚点章）防失控。

---

## 多线交织（三维命运网 · 立项层扩展）

> 梯度（world-gradient.md）给"垂直台阶"，暗线（plot-threads.md）给"水平密网"，但史诗感来自第三维——**线动起来互相撞**。本文规定：每个梯度层 = 新社会版图（新挚友/新敌），且主线×暗线、暗线×暗线须在"逻辑交汇点"交织出小高潮/爆点。完整法则、交叉登记表与示例作品五卷交织蓝图见 `references/thread-weave.md`。

铁律：
- 根基二 初纲每卷须含 **①本卷梯度层 ②本卷新角色网络（新挚友/新敌/中立）③主线×暗线交织矩阵 ④暗线×暗线交叉表**。
- 根基三 角色卡须含【所属阶梯层】【暗线】【暗线交叉（与哪些暗线在哪卷交叉、产出什么）】。
- 根基一 世界构建须含"每层新社会版图"小节，列明每层将登场的新势力/新人物归属。
- 暗线×暗线交叉分三类：信息互补 / 目标冲突 / 身份重叠；每条暗线至少在一处与其他暗线交叉。

## 神话根脉编年史（时间纵轴 · 立项层扩展）

> 梯度（world-gradient.md）是空间横轴、暗线（plot-threads.md）是命运网、多线交织（thread-weave.md）是动态，而**编年史是时间纵轴（时间法则）**——参照古典群像史诗的通用结构：太初创世→法则确立→周期清算→承命者→归位。它规定当世一切力量/器物/血脉/制度的"出厂设置"，是作者"在细微处加戏、掌握剧情"的最高控制面板。完整法则、根脉铁律与示例作品回溯链见 `references/mythic-chronicle.md`。

铁律：
- 根基一 世界构建须含"神话根脉编年史"一节（八纪元：太初→初创→初代→分流→首劫→中劫→当世→超脱），并阐明根命题如何自"血脉稀释之枷"长出。
- 根基二 初纲须附"编年史纪元 × 五卷对照表"，每卷对应编年史的某段回声。
- 根基三 角色卡关键人物须有"编年史坐标"（其血脉/身份源自哪一纪）。
- 根脉铁律：当世每细节回溯某纪（因果闭环）；周期清算机制=定期结算旧账；榜/契=血脉地位根证书；古词皆来历；微小即宏大（从根脉生剧情三段论）。

## 调用协议（单次写作）

1. 翻 `世界构建_*.md` 确认本章涉及的设定/血脉序列。
2. 翻 `初级大纲_*.md` 确认本章在弧光的哪一段、该有什么得失顶点。
3. 翻 `角色库_*.md` 取出场角色的"说话方式"与"忌讳"，照着写台词；**成稿后把本章角色新侧面/新关系/暗线推进回写入该卡「成长记录」与「关系网」**（见 `references/character-evolution.md`，红线只增不减）。
4. `grep 伏笔台账_*.md` 取「待兑现+临近」清单，开工前纳入本章计划；**成稿后把新埋/新兑现更新进台账**（见 `references/foreshadow-ledger.md`）。
5. 写毕跑 Hook 12 门禁（含第9项伏笔闭环与档案生长）+ 根基四两清单 + 古词表，过则存盘，不过则改。
