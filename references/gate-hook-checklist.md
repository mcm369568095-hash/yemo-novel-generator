# 硬卡点门禁检查清单

## 使用说明
每次正文生成后，输出前，逐条检查以下项目。任意一项不通过，禁止输出，退回重写。

## 检查清单

### 1. 边界检查（对照角色边界卡）
- [ ] 所有出场角色的言行是否在边界卡定义的范围内？
- [ ] 是否有角色说出了边界卡「绝不说」中的语句？
- [ ] 是否有角色做出了边界卡「绝不做」中的行为？
- [ ] 角色的决策逻辑是否符合边界卡定义？
- [ ] 是否有角色突然性格大变（无铺垫）？

**不通过标准**：任一角色在任一维度越界。

### 2. 设定一致性检查
- [ ] 是否出现了未铺垫的新设定？
- [ ] 是否推翻了前文已确立的事实？
- [ ] 时间线是否自洽？
- [ ] 空间/地理逻辑是否合理？
- [ ] 能力/规则系统是否前后一致？

**不通过标准**：任何设定矛盾。

### 3. 创作红线检查
- [ ] 是否触犯了用户明确禁止的内容？
- [ ] 是否违背了用户要求的调性/风格？
- [ ] 是否触及了不适宜的主题（按边界规则）？

**不通过标准**：触发任何红线。

### 4. 大纲兑现检查
- [ ] 本章/本篇是否完成了大纲中承诺的推进？
- [ ] 本章/本篇是否兑现了应兑现的伏笔？
- [ ] 是否产生了新的伏笔？（如需要）

**不通过标准**：关键剧情点未推进或关键伏笔未兑现。

### 5. 钩子检查（仅长篇章节）
- [ ] 章末是否有让读者想看下一章的钩子？
- [ ] 钩子是否自然（不刻意）？
- [ ] 本章是否有至少一个未解答的问题留待未来？

**不通过标准**：章末平淡无悬念。

### 6. 语言质感检查
- [ ] 是否通过了行文质感校对（见prose-polish-rules.md）？
- [ ] 是否存在"不是A而是B"类公式化表达？
- [ ] 是否存在教育式总结句？
- [ ] 是否存在过度解释？

**不通过标准**：公式化表达未被替换。

### 7. 文笔质量检查
- [ ] 是否违反 `prose-quality.md`：连续3段同句式 / 情绪标签化 / 万能副词 / 章末安全着陆 / 大段纯解释
- [ ] 是否违反 `prose-polish-rules.md`：不是A而是B / 仿佛…又仿佛 / 某种意义上 / 装饰性破折号堆叠
- [ ] 感官锚点是否到位、节奏是否有变化
**不通过标准**：文笔纪律被违反且未修正。

### 8. 节奏与爽点检查
- [ ] 是否 800–1400 字一个脉冲（短章至少一次实质变化）
- [ ] 爽点/兑现密度是否达标（参考 `cool-points.md` 滚动窗口）
- [ ] 开头是否尽早进入冲突/风险/强情绪
**不通过标准**：节奏塌陷、无爽点脉冲。

### 9. 伏笔闭环与档案生长检查 ⭐新增
- [ ] 本章应兑现的伏笔（来自 `伏笔台账_*.md` 临近项）是否已兑现或推进
- [ ] 本章新埋的伏笔是否已登记入账（编号/类型/锚点/计划兑现）
- [ ] 有无新增未铺垫悬念（红鲱鱼也须登记）
- [ ] 角色库活档案（`角色库_*.md`）是否随本章回写（新关系/新侧面留痕）
**不通过标准**：漏兑重要伏笔 / 新埋未登记（阻断）；角色突破未留痕（不阻断，记入章末自检）。

## 检查报告模板

```markdown
## 门禁检查报告
- **边界检查**：✅/❌ [如❌，说明哪个角色、哪条红线]
- **一致性检查**：✅/❌ [如❌，说明矛盾点]
- **红线检查**：✅/❌ [如❌，说明触犯的红线]
- **大纲兑现**：✅/❌ [如❌，说明未兑现的内容]
- **钩子检查**：✅/❌ [如❌，说明问题]
- **语言质感**：✅/❌ [如❌，说明未过滤的表达]
- **文笔质量**：✅/❌ [如❌，说明违反的纪律]
- **节奏爽点**：✅/❌ [如❌，说明塌陷点]
- **伏笔闭环与档案生长**：✅/❌ [如❌，说明漏兑/未登记/未回写]

**结论**：✅ 通过 / ❌ 不通过，退回重写
**失败原因**：[具体描述]
```

## 常见失败案例

| 失败类型 | 示例 | 修复方法 |
|---------|------|------------|
| 角色说禁用台词 | 让冷面刑警说"我好害怕" | 替换为符合人设的台词 |
| 角色做出禁用行为 | 让坚持程序正义的人伪造证据 | 重写该行为，改为其他合法手段 |
| 出现未铺垫的能力 | 主角突然会飞（之前无铺垫） | 删除或前文加铺垫 |
| 章末无钩子 | 章节结束在"他们回家了" | 加一个疑问/威胁/新发现 |
| 公式化表达 | "不是命运的嘲弄，而是人性的选择" | 改成具体行动和后果 |
| 伏笔漏兑 | 第5章埋的玉坠线索到第50章没下文 | 从伏笔台账取临近项，近期章节安排兑现/回收 |
| 角色未回写 | 某角色本章立了新敌却没进关系网 | 成稿后追加入角色库「成长记录」与「关系网」 |
