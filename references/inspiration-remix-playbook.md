# 经典桥段启发与重混手册

## 核心原则

把经典作品中的桥段转化为**可复用的故事函数**，而非复制具体情节。

**转译公式**：
原著桥段 = 角色关系 + 压力类型 + 选择结构 + 情感Payoff
重混版本 = 新角色 + 新场景 + 新代价 + 同结构但不同结局

## 一、经典桥段卡片库

### 卡片1：最后期限
- **来源信号**：《开端》《土拨鼠之日》《源代码》
- **函数**：角色被困在有限时间内（循环/倒计时/资源耗尽），必须在截止前解决某个问题
- **可重混方向**：
  - 变体A：时间循环+情感修复（不只是解决事件，还要修复关系）
  - 变体B：倒计时+道德困境（时间不够，必须牺牲谁）
  - 变体C：循环+记忆累积（只有主角记得每次循环，别人不记得）

### 卡片2：不可信任的盟友
- **来源信号**：《无间道》《碟中谍》《权力的游戏》
- **函数**：角色身边最亲近/最依赖的人，可能是敌人
- **可重混方向**：
  - 变体A：观众知道但角色不知道（戏剧反讽）
  - 变体B：角色和观众都不知道（最后反转）
  - 变体C：对方自己也不知道（被操控的棋子）

### 卡片3：代价选择
- **来源信号**：某密室悬疑片、某超级英雄电影、某硬科幻名著
- **函数**：角色必须在两个不可接受的选择中做一个
- **可重混方向**：
  - 变体A：选A失去A，选B失去B（两害相权）
  - 变体B：选A暂时安全但后患无穷，选B立刻毁灭
  - 变体C：选A是对的但会被所有人误解，选B是错的但能活命

### 卡片4：身份揭示
- **来源信号**：《星球大战》（我是你父亲）《情书》《嫌疑人X的献身》
- **函数**：某个角色或事件的真实身份/真相在关键时刻被揭示
- **可重混方向**：
  - 变体A：善意隐瞒（为了保护对方一直不说）
  - 变体B：恶意伪装（一直以假身份接近）
  - 变体C：自我认知（角色发现自己才是问题所在）

### 卡片5：无处可退
- **来源信号**：《127小时》《活埋》《隧道》
- **函数**：角色被困在物理或心理的绝境中，所有退路被切断
- **可重混方向**：
  - 变体A：物理困境+心理崩溃
  - 变体B：社交困境（被所有人抛弃）
  - 变体C：系统困境（规则和体制让TA无路可走）

### 卡片6：旧案重翻
- **来源信号**：《杀人回忆》《信号》《白夜行》
- **函数**：过去的案件/事件被重新提起，揭示出与现在相关的秘密
- **可重混方向**：
  - 变体A：过去的加害者现在是受害者
  - 变体B：过去看似解决的事，其实方向完全错了
  - 变体C：过去和现在的案件是同一只手的操作

### 卡片7：陌生人闯入
- **来源信号**：《老无所依》《狗十三》《寄生虫》
- **函数**：一个外来者进入稳定系统，打破所有平衡
- **可重混方向**：
  - 变体A：外来者是拯救者，但代价巨大
  - 变体B：外来者是掠夺者，系统被摧毁
  - 变体C：外来者什么都没有做，只是存在本身就造成了崩塌

### 卡片8：公开证明
- **来源信号**：《十二怒汉》《正义的算法》《社交网络》
- **函数**：主角必须在公开场合证明某件事，面对质疑和压力
- **可重混方向**：
  - 变体A：证明自己（洗清冤屈/捍卫专业）
  - 变体B：证明真相（所有人都相信谎言）
  - 变体C：证明某个人（为无法说话的人发声）

## 二、重混规则

### 规则1：至少改三项
从以下维度中至少改动3项，才算「重混」而非「借用」：
- 设定/时代
- 角色关系
- 核心代价
- 结局方向
- 道德立场
- 具体道具/符号

### 规则2：换代价
经典桥段中的「代价」往往固定在某个类型上。重混时更换代价类型：
- 原：生命代价 → 改：记忆代价
- 原：爱情代价 → 改：尊严代价
- 原：金钱代价 → 改：信任代价

### 规则3：反向操作
把经典桥段的方向反转：
- 原：找出凶手 → 改：找出谁不是凶手
- 原：拯救某人 → 改：某人不需要被拯救，是主角需要被拯救
- 原：揭开真相 → 改：永远无法知道真相，但角色选择接受

## 三、组合引擎

多个卡片可以组合使用：

| 组合 | 产生效果 |
|------|---------|
| 卡片1（最后期限）+卡片7（陌生人闯入） | 紧张感加倍，外来者可能是救星也可能是变数 |
| 卡片4（身份揭示）+卡片2（不可信任的盟友） | 双重反转，刚以为安全了，结果又出事 |
| 卡片6（旧案重翻）+卡片3（代价选择） | 过去的真相让人不得不做两难选择 |
| 卡片5（无处可退）+卡片8（公开证明） | 绝境中唯一的出路是在所有人面前证明自己 |

## 四、风格信号转译

当用户说「想要类似XX作品的感觉」：

| 用户说 | 转译为故事函数 |
|--------|---------------|
| 想要《隐秘的角落》的感觉 | 小孩视角+大人世界的黑暗+看似无害的角色最危险+开放式结局 |
| 想要《我的解放日志》的感觉 | 日常的疲惫感+微小反抗+角色之间不说出口的理解+缓慢但确实的变化 |
| 想要《漫长的季节》的感觉 | 时间跨度的沉重+过去的幽灵+普通人在大时代中的无力+最终的和解或放下 |
| 想要《狂飙》的感觉 | 一个人如何一步步走到对立面+兄弟情与利益的分裂+时代洪流下的选择 |
| 想要《食神》的感觉 | 从顶峰跌落→底层重生→公开复仇+食物作为情感载体+荒诞中的真实 |

**注意**：只使用可泛化的情感/结构信号，不复制具体角色名、地名、标志性台词。
