# 知识库来源声明（knowledge/）

本目录下的 9 份 CSV 知识库，来源于开源项目 **webnovel-writer**（作者 lingfengQAQ）。

- **原始协议**：GPL-3.0
- **引入目的**：本地融合学习，强化「夜秣小说生成器」的写作知识资产（技法 / 人设 / 桥段 / 爽点 / 命名 / 场景 / 金手指 / 裁决 / 题材）。
- **使用范围**：仅用于本地创作与技能融合。**若未来对外分发本技能（如 SkillHub 发布），须遵守 GPL-3.0 义务**——保留原作者版权与协议文本，并开源衍生内容。

## 文件清单

| 文件 | 内容 |
|------|------|
| 人设与关系.csv | 人设类型、核心动机、行为逻辑、互动模式、毒点 |
| 写作技法.csv | 对话声线、情感递进、节奏等技法，含正例/反例/毒点 |
| 命名规则.csv | 玄幻/都市等题材角色与地点命名规范 |
| 场景写法.csv | 战斗、对话、氛围等场景模式与示例 |
| 桥段套路.csv | 退婚流、追妻火葬场等经典桥段的前置/爽点/转折/反套路 |
| 爽点与节奏.csv | 压抑爆发、微反转等节奏调动手法 |
| 裁决规则.csv | 各题材风格/爽点/节奏优先级裁决 |
| 金手指与设定.csv | 力量体系、异能代价等设定边界 |
| 题材与调性推理.csv | 题材路由、核心调性、节奏策略 |

> 注：上述规则的核心要点已重写为 yemo 语境，落在 `prose-quality.md` / `cool-points.md` / `review-dimensions.md`，本目录 CSV 作为可检索的原始知识库保留。
