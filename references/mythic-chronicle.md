# 神话根脉编年史（Chronicle）× 立项层第八块拼图

> 核心命题：**梯度是空间横轴（势力塔），暗线是命运网，多线交织是动态，编年史是时间纵轴（时间法则）。四者正交，才是"时空人"俱全的史诗架构。**
> 通用原型：太初创世（分化）→ 初代立法（确立秩序）→ 周期清算（结算旧账）→ 承命者（受托执行）→ 名录定序（重新排位）。这套编年史本身，就是一部"起源契约 + 周期结算机制"。
> 工作范例见 `你的作品目录/示例项目/世界构建_血脉源流与终极秘密.md` 的「神话根脉编年史」一节。

---

## 一、为什么需要这一层（史诗感的根）

用户洞察（原话转述）："我们要从根子上面出一个世界观，从世界的起源一路写到秩序确立、再到周期清算，从头到尾完整呈现。这样，才能在细微处增加剧情、掌握剧情。"

前几层解决了：
- **梯度（§1.6）**：世界有垂直纵深（空间横轴）。
- **暗线（§1.5）/ 多线交织（§1.7）**：故事水平织密、线动互撞。

但缺"**时间纵轴**"——读者知道"上面还有一层"，却不知道"这一切从哪来、为何如此"。没有编年史，当世再精巧的细节也只是"悬空布置"；有了编年史，一枚玉坠、一句古词、一个姓氏背后都有**万年史的重量**，作者才能在细微处"有据可依地加戏、掌握剧情"。

编年史不是背景附录，是**最高层的"控制面板"**：它规定了当世一切力量、器物、血脉、制度的"出厂设置"，任何剧情点都能在它身上找到根。

## 二、编年史模板（纪元制 · 可裁剪/可扩展）

按上述通用原型，世界史切成若干**纪元**（每个纪元是一个"纪元动因"）。通用八纪元骨架：

| 纪元 | 纪元动因 | 通用原型 | 当世遗产（给后世的"根"） |
|---|---|---|---|
| **太初纪** | 混沌/原初灵潮，万物未分 | 混沌未分 | "源"漂流于根，一切之始 |
| **初创纪** | 第一缕秩序成形，划分清浊 | 创世分化 | "源"凝为**源脉本源**悬于世界根处 |
| **初代纪** | 初代纯血临世、立源脉谱记血脉纯度 | 初代立法 | 立"血脉为尊"之序；镇源脉玉印（血脉印前身） |
| **分流纪** | 血脉分流，盟友/敌对确立 | 诸族分野、分封 | 同源分流谱系定格；**名录机制**立（源脉谱） |
| **首劫纪** | 第一次周期清算 | 初次清算 | 第一代守脉人承命、化魂寄玉、创守脉人一脉；战后定万脉新序 |
| **中劫纪** | 历次周期清算循环（枯潮周期） | 后续清算余波 | 每隔周期守脉人承命留名；当世诸势力皆是余脉 |
| **当世纪** | 主角所处时代（上一劫余波+下一劫将至） | 故事当下 | 主角为**当代承命者**；一切暗线在此收口 |
| **超脱纪** | 破限/飞升序列（预留续作） | 超越既定秩序 | 突破"血脉为天"，飞升接口开启 |

> 裁剪规则：小书可砍掉太初/初创只留立脉之后；大书（含飞升）保留全八纪并把"超脱纪"做成续作钩。

## 三、根脉铁律（灵魂 · 史诗感的操作手册）

### 铁律 1 · 因果根脉闭环
当世**每一个细微设定**（器物 / 古词 / 姓氏 / 功法 / 血脉异象 / 一处雕刻）都必须能**回溯到编年史某一纪元节点**。读者读到一个词，要感到"它背后有万年史"。
- 反例：凭空出现一件"上古神兵"却无来历。
- 正例：玉坠 = 首劫纪第一代守脉人化魂寄玉；"枯潮"一词 = 中劫纪源脉本源将竭的时间法则；照壁雕刻 = 分流纪名录图样。

### 铁律 2 · 周期清算机制（通用原型）
每隔一定周期触发**"周期清算"**——秩序自行结算、守脉人（承命者）出世、战后"名录"重排有功血脉。**主角 = 当代承命者**，这让"为什么是主角"有了史诗级的正当性，而非运气。

### 铁律 3 · 名录 / 契约机制
存在一个**"源脉谱 / 血脉册"**（命名可换），记录历代守脉人与封赏，是当世所有血脉地位的**"根证书"**。谁在榜上、谁被除名，全是剧情筹码。
- 应用：沈彻（第37任）失踪 = 榜单除名风波；沈砚（第38任）继任 = 榜单正名。一除一正，就是父子暗线的史诗级根由。

### 铁律 4 · 古词皆来历
任何生僻古词 / 仪式 / 器物，必须在编年史有出处；写时当众轻解（呼应根基四"古词解释"）。

### 铁律 5 · 微小即宏大（从根脉生剧情的三段论）
这是用户"在细微处增加剧情、掌握剧情"的**可操作方法**：
1. 要加一个剧情点？先问它属于编年史**哪一纪**。
2. 该纪的律令 / 人物 / 器物是什么？
3. 让当世事件成为该纪律令的"**当代回声**"。
- 案例：想写"主角在某古庙发现残碑" → 残碑 = 首劫纪某承命者临终留字 → 碑文揭示枯潮周期 → 推进终极秘密。于是"一块破碑"自动承载万年史与主线推进，且逻辑自洽。

### 铁律 6 · 通俗化（先讲人话，后长机制）⭐ 用户血泪教训
**概念不生造。** 作者最容易犯的错，是先把一套抽象术语甩给读者（"这世界由源池/枯潮/归源者/超脱之枷统治"），再用大段注释补课——读者一头雾水，代入感当场碎裂。
正确姿势是**反过来**：先用一段"创世传说"把世界的来龙去脉当故事讲明白（秩序分化 → 源脉化万物 → 初代纯血 → 血脉稀释 → 战争陨落 → 混血衰弱 → 枯潮周期清算），**让所有机制都从这段故事里自然长出来**：
- "源脉谱/血脉册" = 初代立来记录血脉纯度的册子；
- "守脉人/承命者" = 初代陨落后代际守护源脉的人；
- "稀释之枷" = "血脉越传越淡"这一最朴素天理的具名；
- "枯潮" = 源脉如海潮退去之劫。
读者读完传说，自然懂这些词，无需注释。**检验标准**：删掉所有术语解释，单看创世传说那段，读者能否说清"这世界为什么血脉为尊、为什么一代不如一代"。能，才算过关。

## 四、编年史 × 根基四文档 / 梯度 / 暗线 对接

- **编年史（纵轴）× 梯度（横轴）正交**：临渊城（微观层）对应当世纪的"末梢"；隐族（世界层）对应分流纪的"余脉真相"；飞升（超验层）对应超脱纪。任一梯度层都能在编年史找到它的"纪元切片"。
- **每卷 = 编年史的一段回声**：见 `初级大纲_*.md` 的"编年史纪元 × 五卷对照表"——卷一临渊=当世末梢、卷二九衢=中劫余波、卷三大胤=首劫名录遗制、卷四隐族=分流余脉真相、卷五超脱=超脱纪。
- **暗线人物皆有"编年史坐标"**：沈彻被隐族带走（分流纪余脉的当代回响）、苏晚凤凰血脉（分流纪盟友遗族）、福伯守脉人暗卫（首劫纪名录后裔）。暗线因此不只是"个人恩怨"，而是"万年史在个人身上的投影"。
- **根命题反推**：根命题须能从血脉稀释之枷中长出（如"血脉为天"之枷 → 主题"超越血脉为天"）。

## 五、示例作品的神话根脉编年史（工作范例）

完整版见同名世界构建文档「神话根脉编年史」一节，此处列骨架：

- **太初纪**：混沌中唯"源脉"漂流，万物未生。
- **初创纪**：秩序分化，源脉流淌演化，山川生灵皆出其体——这世界是源脉生的。
- **初代纪**：源脉育出初代，分衍人族/妖族等；初祖立"源脉谱"记血脉纯度，"血脉为尊"自此始。
- **分流纪**：初祖逝，血脉依亲疏分流定格；盟友与敌对确立；归墟氏生"归还源脉"之念（血魂殿思想雏形）。**源脉谱（血脉册）立**。
- **首劫纪（初代陨落）**：万族大战，初代凋零，混血时代开启；第一位守脉人**沈尘**化魂寄玉，镇源脉密钥，创守脉人一脉；战后定万脉新序。
- **中劫纪（枯潮循环）**：源脉枯潮周期成型，混血一代代更弱；第37任守脉人**沈彻**触密钥，引祖地脉觉醒——当世纪引信。
- **当世纪（主角时代）**：第38任**沈砚**（示例设定：没落旁支子弟）；玉坠发烫 = 祖地脉觉醒 = 新一轮枯潮将至 = 当代周期清算启动。沈彻失踪、二房夺嫡、血魂殿窃池、隐族降临，皆是中劫纪律令的当代回声。
- **超脱纪（预留）**：破"血脉稀释"之枷，重接源脉，飞升序列开启。

> 由此，当世一切细节皆可回溯：玉坠→首劫纪沈尘化魂；枯潮→中劫纪周期律；祖地脉发烫→当世纪引信；照壁刻图→分流纪名录图样；"守脉人"古词→首劫纪名录术语。作者握此控制面板，便能在细微处自由加戏而不崩。
