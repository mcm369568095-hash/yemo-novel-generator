# 输出规范

## 一、短篇输出要求

### 1.1 长度
- 默认：1800-4000中文字符
- 用户可指定任意长度

### 1.2 结构
- 必须有开篇钩子（前3段内制造扰动）
- 必须有至少3次升级
- 必须有结尾余味
- 不能以"于是他/她明白了……"结束

### 1.3 语言
- 通过行文质感校对
- 对白占比建议：悬疑类30-40%，言情类40-50%，动作类20-30%
- 每段不超过200字（特殊场景除外）

## 二、长篇章节输出要求

### 2.1 长度
- **默认：3000-4500 中文字符/章**（本书项目硬指标 ≥2800，目标 3000）
- 用户可指定；低于 2800 视为未达标，须补密度后输出
- 每章须为完整「场景块」：≥2 节拍、≥1 得失顶点、章末留钩

### 2.2 结构
- 章首：前情提要（1-2句，仅当非第一章）
- 正文：有起承转合，但保持未完成感
- 章末：钩子（1-2句预告，不解释）

### 2.3 连载一致性
- 严格遵守角色边界卡
- 严格遵守已确立事实
- 每章推进至少1个主线节点，兑现或埋设至少1个伏笔

### 2.4 密度与通读前置（本书项目强制）
- **通读(必做)**：每章生成前，必须先通读 `大纲`(定位本卷弧光+本章在卷内章节地图) + `角色库`(出场角色说话方式/忌讳/关系) + `文风与写作规范_习惯文件`(文风与密度要求) + 前情(近3-5章) + `伏笔台账`(待兑现/临近项)，确认本章定位与得失顶点后再落笔。
- **不简介**：禁止概要式时间跳跃（「几年后」「转眼」「他修炼了一阵」），时间推移靠具体场景与动作接动作展现。
- **每章≥2线推进**：主线 + 至少1条暗线/支线同时有进展；允许多线交织，但须逻辑交汇点自然。
- **追更钩子**：章末必须留未闭合问题/升级/反转，读者合不上书。

## 三、禁止项

### 3.1 内容禁止
- 不复制受保护文本
- 不直接模仿在世作者
- 不违反用户设定的红线

### 3.2 表达禁止
- 不使用"不是A而是B"结构
- 不使用"仿佛……又仿佛……"
- 不使用教育式总结
- 不使用"某种意义上/某种程度上"
- 不使用堆叠破折号
- 不使用概要式时间跳跃旁白（「几年后」「转眼」「他修炼了一阵」须改为场景展现）
- 不使用「简介式」吞过程叙述（把多步进展一口吞掉的流水账）

## 四、输出前自查

每次输出前确认：
1. 钩子是否在开篇3段内？
2. 冲突是否至少升级3次？
3. 结尾是否有余味/钩子？
4. 是否通过行文质感校对？
5. 是否通过角色边界卡检查？
