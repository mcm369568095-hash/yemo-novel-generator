# 主线-暗线架构（内容线路设计法）

> 定位：根基四文档决定了"写什么"（世界观/弧光/角色/逻辑），但根基四文档之下还差一条**线路纪律**——**主角主线 + N 条人物暗线**，把故事从"一条线推进"织成"一张网"，才能丰满成史诗。本文件定义暗线的构建、交汇与防崩法则，是根基四文档（尤其根基二初纲、根基三角色）的线程化扩展。
> 工作范例（已落地可照搬）：《示例项目》沈彻（父）暗线双分支。

## 总纲：一张网，不是一条线

```
        根基一·终极秘密（网的中心）
              │
    ┌─────────┼─────────┐
 主线：主角征途      暗线A：父亲      暗线B：伴侣/朋友
（根基二五卷弧光）  （死因/真相）   （各自人生线）
    │                │              │
    └────交汇点──────┴──交汇点──────┘
        = 小高潮 = 爆点 = 主线升级
```

- **主线**：主角对"终极秘密"的征途（根基一终极 + 根基二弧光），全程显形。
- **暗线**：每个关键人物（父/伴侣/朋友/重要反派）各有一条"人生线"，前期只露钩子不显全貌。
- **交汇点 = 爆点**：暗线不是装饰，是"主角走到某处，暗线突然撞上来"的戏剧钩子。交汇处必须产出小高潮或揭开一层真相。

## 暗线的两种开局母题（以"父亲"为例）

### 母题 A · 父已死（追寻死因）
- 前期：主角因父死踏上征途 → **父亲即前期暗线**。
- 钩子：谁杀的？为何杀？凶手与主角以为的"明显嫌疑人"是否一致？
- **爆点机制（红鲱鱼法）**：若真凶不是最明显的嫌疑人（如众人都以为是二房），则——引入新冲突 + 新敌人 + 小高潮。这是"假红鲱鱼→真凶揭晓"的经典爆点，且真凶往往牵出更大势力/更早的阴谋，使主线直接升级。
- 延伸：父死背后藏着与终极秘密同源的真相（父亲可能正是触及终极秘密而遭灭口的第一人）。

### 母题 B · 父未死（假死/失踪/被囚）
- 父亲去做了什么？三种走法：
  1. **组建势力**：自组团队/组织，追查某真相（与终极秘密同源）。
  2. **为子铺路**：以身入局、提前布局，把资源/情报留给主角。
  3. **被迫离场**：被囚/被迫远走，等待被救或时机。
- **爆点机制（归来法）**：在意想不到处现身助主角，成为一大助力。读者以为死了的人带着资源/情报回来，是强情绪爆点 + 战力/情报补完。

> 母题 A 与 B 可叠加：前期以为父死（A 钩子），中途揭"假死"（转 B），再揭"当年假死是因真凶追杀"（回 A 升级）。双重反转最炸。

## 暗线的"逻辑铁律"（防崩，呼应根基四）

1. 每个暗线人物须有：**出身背景 + 与主角相遇的"事件因" + 各自的人生目标（≠主角目标）+ 交汇触发条件**。
2. **相遇靠事件不靠巧合**：他们因何事、在何地被命运捆到一起，必须前置铺垫（禁止"刚好路过就成挚友"）。
3. **早埋锚点**：暗线每揭一层，首提须至少提前一章露一个可见信号（呼应根基四"关键设定先铺后亮"）。
4. **暗线有独立得失**：暗线人物自己的人生也有"得失顶点"，不是主线的提线木偶。

## 暗线 × 暗线 交织（暗线互撞 · 史诗级）

> 暗线之间**不是平行不交的河**——它们会互相穿越，在交叉点炸出比单线交汇更猛的爆点。这是 `references/thread-weave.md` 的核心内容，此处给设计骨架。

三类交叉：
- **信息互补型**：A 知 X、B 知 Y，合流揭 Z（如沈彻知"源脉密钥真相"、苏晚知"罗盘指向"，合流揭同源分流真相）。
- **目标冲突型**：A 要护主、B 要复仇，撞出张力（如苏晚要杀二房、主角要保二房结盟抗外敌，张力爆表）。
- **身份重叠型**：A 的仇人 = B 的恩人，或 A 与 B 早有默契（如沈彻与福伯早有暗卫默契，卷四合流）。

**暗线交叉登记表**（哪两条线 × 第几章 × 因何交叉 × 产出什么）。每条暗线须在**至少一处**与其他暗线交叉，避免"各行其是"。

## 暗线 × 根基四文档 对接

- **根基一**：暗线的"真相"应汇入/扰动终极秘密（父之死因可能正是终极秘密的入口）。
- **根基二**：每卷初纲须标注"本卷激活/推进哪条暗线、在第几章与主线交汇、交汇产出什么小高潮"。
- **根基三**：角色卡新增【暗线】字段——该人物自己的人生线、与主线交汇点、揭晓方式。

## 案例速写 · 沈彻（父）暗线双分支（可直接入示例作品角色库/初纲）

**既有设定锚点**：沈彻 = 嫡脉第 37 任"血脉印"宿主，主角之父；二房沈鹤年（笑面虎）觊觎嫡脉密钥；血魂殿三百年前觊觎地脉、窃血无源；终极秘密 = 源脉本源/枯潮/守脉人。

**分支 A（父死于非二房 · 红鲱鱼爆点）**：
- 表面：全府（含主角）以为沈彻之死是二房沈鹤年夺嫡暗杀 → 主角前期目标"向二房复仇"自然成立，读者代入。
- 钩子预埋：第 1 章玉坠发烫时，老祖残魂一句"你爹不是死在自家刀下"被主角忽略（早埋锚点）。
- 爆点：大比/争流卷中揭——真凶是**血魂殿**（当年为夺源脉密钥跨界灭口沈彻），二房只是被利用的棋子。→ 引入新敌人（血魂殿主）、主线从"家族内斗"升级为"万脉存亡"，主角与二房关系也从"死仇"转为"被迫结盟对抗外敌"的复杂张力。

**分支 B（父未死 · 归来助力）**：
- 沈彻当年为假死：作为第 37 任宿主，他先于老祖感知"枯潮将至、血魂殿将醒"，以身入局——假死脱身潜入源脉本源外围，组建"守脉人遗脉"小组织追查逆血归源之法。
- 爆点：主角在归源卷（卷四）绝境时，沈彻携"遗脉"与源脉密钥线索现身，既补战力又补世界观盲点，并成为揭开"血脉稀释之枷"的关键拼图。

**叠加打法（推荐）**：前期 A（以为是二房）→ 中段揭真凶是血魂殿（A 升级）→ 卷四揭沈彻当年是假死、一直在铺路（转 B 归来）。三重信息差，读者全程"以为懂了又错"，爽感与厚度拉满。
