# 行文质感校对表

## 核心理念
AI写文最常见的翻车点不是情节，而是**语言模式**。读者一看到公式化表达就会出戏。

本规则的目标：**让叙事读起来自然口语，减少公式化腔调。**

---

## 一、必须删除/替换的表达模式

### 1.1 对比式伪深度句
**特征**：用"不是A，而是B"来制造"深刻感"。

**AI典型**：
- "不是命运的嘲弄，而是人性的选择。"
- "这不是一个关于复仇的故事，而是一个关于救赎的故事。"
- "他害怕的不是死亡，而是被遗忘。"

**替换方法**：直接说明B，不要对比A。
- 改："他怕的不是死。是没人记得他活过。"
- 改："复仇是幌子。他想要的是有人为他掉一滴泪。"

**例外**：仅在刻意使用角色口吻时允许（如：侦探说"这不是谋杀，是表演。"）

### 1.2 模糊叠加句
**特征**：用"仿佛……又仿佛……"来糊弄描述。

**AI典型**：
- "她仿佛看到了希望，又仿佛看到了更深的绝望。"
- "他仿佛听到了什么，又仿佛只是错觉。"

**替换方法**：写具体感官细节，让读者自己判断。
- 改："她看到光从裂缝里漏进来。一秒后，裂缝又被堵死了。"
- 改："他听到一声响。回头，什么都没有。"

### 1.3 教育式过渡句
**特征**：替读者总结"意义"。

**AI典型**：
- "这让我们不禁思考，什么是真正的正义。"
- "那一刻，他明白了人生的真谛。"
- "生活就是这样，在不经意间教会我们成长。"

**替换方法**：删掉。让读者的情绪来自情节本身。
- 改：直接删，跳到下一段动作/对白。

### 1.4 装饰性破折号堆叠
**特征**：频繁使用破折号——像这样——来连接句子。

**AI典型**：
- "他推开门——里面没有人——但他知道——有人在看着他。"
- "她想起那天——那天下着雨——他说了那句话——然后就走了。"

**替换方法**：拆成短句，用句号或逗号。
- 改："他推开门。里面没人。但他知道有人看着他。"
- 改："她想起那天下着雨。他说完那句话就走了。"

### 1.5 "某种意义上"类模糊限定
**AI典型**：
- "某种意义上，他是对的。"
- "某种程度上，这算是一种解脱。"

**替换方法**：要么说清楚，要么删掉。
- 改："他对了。但我们付不起对的代价。"
- 改："这算解脱？她不确定。"

### 1.6 解释性对白标签
**AI典型**：
- "他解释道""她补充道""他陈述道"——用X道来告诉读者语气。

**替换方法**：用动作+简短"说"，或直接不用标签。
- 改：他耸肩。"我没拿。"
- 改："我没拿。"他把空口袋翻出来。

## 二、替换对照表

| AI原文 | 替换建议 |
|--------|---------|
| 某种意义上，他是对的 | 他对了。但（具体后果） |
| 她仿佛看到了希望 | 她盯着那道光。手在发抖。 |
| 不是A，而是B | 只有B。（或用角色口吻） |
| 那一刻，他明白了 | [具体行动/对白表现明白] |
| 让我们不禁思考 | [删掉] |
| 他解释道（语气词） | [动作]+他说，或不用标签 |
| 与其说A，不如说B | 可能是B吧。（用角色怀疑口吻） |
| 最终，他终于 | 只留"终于"，删"最终" |
| 不知为何 | 删掉，或写出具体原因 |
| 某种程度上 | 删掉 |

---

## 三、逐句过滤流程

生成正文后，逐句检查：

1. ✅ 有"不是……而是……"结构？→ 重写
2. ✅ 有"仿佛……又仿佛……"？→ 重写
3. ✅ 有"某种意义上/某种程度上"？→ 删除或重写
4. ✅ 有教育式总结句？→ 删除
5. ✅ 有3个以上破折号在同一段落？→ 拆分
6. ✅ 对白标签用了解释性动词（解释/补充/陈述）？→ 改为"说"或直接动作
7. ✅ 有"最终""终于"堆叠？→ 只留一个
8. ✅ 有"不知为何"？→ 要么写明原因，要么删掉

**目标**：每千字不超过1处"残留AI味"表达。

## 四、示例：修改前后对比

### 修改前（AI味浓）
> 某种意义上，林霜是对的。不是因为她比其他人更聪明，而是因为她比任何人都更明白，真相从来不会自己浮出水面。她仿佛看到了什么，又仿佛只是凭直觉在行动。最终，她终于推开了那扇门——里面空无一人——但她知道——有人在看着她。

### 修改后
> 林霜是对的。真相从来不会自己浮出来。她推开门。没人。但后颈的汗毛竖起来了。有人看着她。

**减少了**：57字 → **减少了**：对比式深度句、仿佛叠加、破折号堆叠、最终终于堆叠。
**增加了**：身体反应（后颈汗毛竖起），画面感更强。
