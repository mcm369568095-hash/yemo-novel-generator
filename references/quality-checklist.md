# 质量自查清单

## 七项核心检查

### 1. 钩子力度
- [ ] 开篇前3段内是否发生了某种「扰动」？（一个事件、一句反常的话、一个不协调的画面）
- [ ] 这个扰动是否让读者产生了「然后呢？」的冲动？
- [ ] 开篇是否制造了错误的类型预期？（如：诗意的句子让读者以为是文艺片，结果是悬疑）

**不通过标准**：前3段在交代背景，没有事件发生。

---

### 2. 角色欲望清晰度
- [ ] 主角是否有一个明确的、可见的欲望？（读者能说出「TA想要____」）
- [ ] 这个欲望是否足够驱动整篇故事？（不是可有可无的小事）
- [ ] 读者是否知道：主角得到了这个欲望会怎样，得不到又怎样？

**不通过标准**：主角是「被事情推着走」的被动型，读者不清楚TA想要什么。

---

### 3. 冲突升级节奏
- [ ] 冲突是否至少升级了3次？（每次比上次更严重）
- [ ] 每次升级是否改变了局面——不只是「更难了」，而是「选项更少了」？
- [ ] 主角是否每次都有主动选择（不只是被动反应）？

**不通过标准**：冲突是线性的（从A到B到C），没有转折和代价。

---

### 4. 对白张力
- [ ] 对白是否推进了剧情或揭示了人物？（不只是闲聊）
- [ ] 每句对白是否都有「隐藏意图」？（字面意思和真实意思有距离）
- [ ] 是否避免了「信息性对白」？（角色说出观众已经知道的信息，纯为交代）

**不通过标准**：对白只是交换信息，没有潜台词，没有情绪暗流。

---

### 5. 画面感
- [ ] 关键场景是否有具体的感官细节？（视觉、听觉、触觉、嗅觉至少用到两种）
- [ ] 是否用「身体反应」代替了「情绪标签」？（写「手在发抖」不写「他很害怕」）
- [ ] 是否有至少一个「细节特写」成为情感锚点？（一个物件、一处气味反复出现）

**不通过标准**：描写停留在形容词层面（很冷、很黑、很怕），没有具体物象。

---

### 6. 反转/悬念
- [ ] 是否有至少一次「让读者意外的揭示」？
- [ ] 这个揭示是否在前文有迹可循？（不是硬反转，读者回头能找到暗示）
- [ ] 结尾是否留有「余味」？（不是把一切说明白、总结完）

**不通过标准**：结尾把一切都解释了，没有留给读者想象空间。

---

### 7. 开篇清晰度
- [ ] 开篇的「字面事件」是否明确？（读者不会误解「到底发生了什么」）
- [ ] 如果使用了诗意的比喻或压缩表达，是否在同一句或下一句给出了具体锚点？
- [ ] 读者是否知道「这是一个什么类型的故事」？（是悬疑就不会让人以为是言情）

**不通过标准**：开篇让读者困惑「到底发生了什么」「这是在讲什么」。

---

## 修复对照表

| 检查项 | 如果失败 | 怎么修 |
|--------|---------|--------|
| 钩子力度不足 | 把第一段改成「某件反常的事正在发生」，把背景交代移到后面去 |
| 角色欲望模糊 | 给主角一个「想要的东西」和一个「阻碍」，在前3段内点明 |
| 升级不够 | 每段冲突结束后，让主角「失去一个选择」而不是「变得更累」 |
| 对白平淡 | 重写对白，让每一句都隐藏「威胁/请求/试探/欺骗」之一 |
| 画面感弱 | 选一个物象反复出现（灯光/气味/伤口/某件物品），让它承载情感 |
| 没有反转 | 在故事中段或结尾，让一个「你以为的」被推翻，且前文有暗示 |
| 开篇误读 | 在诗意句后紧接一个具体动作或具体事件，锚定字面意义 |
| 结尾无余味 | 最后一句回到开篇的某个细节，让读者发现「原来之前那个细节是这个意思」 |
