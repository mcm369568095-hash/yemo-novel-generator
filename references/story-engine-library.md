# 故事引擎库

## 一、情感Payoff类型

| 类型 | 核心体验 | 适用场景 |
|------|---------|---------|
| **正义实现** | 读者看到"恶有恶报" | 悬疑、犯罪、复仇 |
| **真相揭示** | 读者和角色同时获得"原来如此" | 推理、悬念、家庭秘密 |
| **关系转变** | 从敌对/陌生到信任/爱 | 言情、职场、公路 |
| **自我救赎** | 角色完成对过去错误的弥补 | 成长、家庭、战争 |
| **幸存** | 读者与角色共度极端处境 | 灾难、末世、求生 |
| **选择代价** | 角色得到想要的，但失去更重要的 | 任何严肃类型 |
| **希望** | 在绝境中找到一丝光亮 | 任何类型 |

## 二、高压力关系类型

| 关系 | 张力来源 | 经典模式 |
|------|---------|---------|
| **师徒** | 期望与背叛/超越 | 《霸王别姬》程蝶衣与段小楼 |
| **搭档** | 互补与冲突并存 | 警探搭档、合伙人 |
| **敌对** | 互相理解但必须对立 | 侦探与罪犯、敌对家族的子女 |
| **三角** | 竞争与选择的痛苦 | 情敌、权力竞争 |
| **血脉** | 义务与怨恨交织 | 父子、母女、兄弟 |
| **战友** | 共同目标下的牺牲 | 战争、末日小队 |

## 三、情节引擎

### 3.1 悬念引擎
- **未知威胁**：角色知道危险存在，但不知道是什么/什么时候来
- **不可靠叙述**：角色/叙述者可能隐瞒或误判
- **时间压力**：倒计时、即将到来的截止点
- **信息不对称**：读者知道的比角色多，或相反

### 3.2 困境引擎
- **两难选择**：选A害一个人，选B害另一个人
- **背叛危机**：信任的人可能不可信
- **系统冲突**：个人的良心vs组织的规则

### 3.3 升级引擎
- **公开化**：隐藏的事被更多人知道
- **牵连者**：无辜的人被卷入
- **资源耗尽**：钱、时间、体力、关系在减少
- **成功反噬**：一次成功导致了更糟的后果

## 四、升级阶梯（至少3层）

**示例（悬疑）**：
1. 第一层：主角发现一个疑点
2. 第二层：主角调查时，有人警告她"别多管闲事"
3. 第三层：她继续查，线人死了
4. 第四层：她发现自己也被盯上了
5. 第五层：她发现举报者是她最信任的人

**示例（言情）**：
1. 第一层：两人互相看不顺眼
2. 第二层：被迫合作，发现对方不全是自己想的那样
3. 第三层：发生一件事，让他们看到对方脆弱的一面
4. 第四层：外部压力逼他们站在一起
5. 第五层：其中一个为了另一个主动放弃

## 五、钩子库（开篇/章末）

### 开篇钩子（前3段内）
- **反常细节**："她在父亲的遗物里找到一盒新的录音带。但父亲死了三年了。"
- **危险提问**："你确定要查这个案子？上一个查的人在医院，还没醒。"
- **日常崩塌**："早上八点，他还是个普通会计。八点十七分，他手里有了一把枪。"
- **身份悬念**："他们在找的人，长得和我一模一样。但我知道，我根本没有兄弟。"
- **代价前置**："她签了那份合同。后来她才知道，她卖掉的不是时间，是记忆。"

### 章末钩子（长篇连载）
- **新信息**："他翻到最后一页，照片上的人——是他自己。二十年前的他。"
- **威胁临近**："门外传来脚步声。不止一个。"
- **关系反转**："她说了谢谢。他没说不用谢。因为他知道，他回不了头了。"
- **资源耗尽**："药还剩三粒。到基地还要五天。"
- **秘密浮出**："那个被她亲手送进监狱的人，今天出狱了。"
