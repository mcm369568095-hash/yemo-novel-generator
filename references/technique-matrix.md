# 技法矩阵

## 技法引擎分类

### A类：叙事节奏
| 技法 | 说明 | 使用场景 |
|------|------|---------|
| **短句留白** | 用短句制造紧张感，句号比逗号多 | 悬疑、紧张场景 |
| **场景切换** | 不交代"与此同时"，直接切 | 多线叙事 |
| **延迟揭示** | 先给结果，后说原因 | 开篇钩子 |
| **加速/减速** | 紧张时用短句加速，抒情时用长句放缓 | 节奏控制 |

### B类：对白张力
| 技法 | 说明 | 使用场景 |
|------|------|---------|
| **潜台词** | 对白字面意思和真实意图相反 | 任何场景 |
| **不回答** | 角色用问题回答问题 | 回避/试探 |
| **打断** | 对话被打断，信息不完整 | 制造紧张 |
| **沉默** | 用动作代替对白 | 情感高潮 |

### C类：视角控制
| 技法 | 说明 | 使用场景 |
|------|------|---------|
| **有限视角** | 读者只知主角所知 | 悬念 |
| **不可靠叙述** | 角色认知可能是错的 | 反转 |
| **镜头外信息** | 角色没看到的，读者也不看 | 保持代入感 |

### D类：感官描写
| 技法 | 说明 | 使用场景 |
|------|------|---------|
| **单一感官聚焦** | 一段只突出一种感觉（触觉/嗅觉/听觉） | 沉浸体验 |
| **身体反应代替情绪** | "胃在抽"代替"他害怕" | 任何场景 |
| **细节特写** | 放大一个物件的细节，暗示意义 | 伏笔 |

### E类：结构
| 技法 | 说明 | 使用场景 |
|------|------|---------|
| **闭环** | 结尾呼应开头的细节或台词 | 短篇 |
| **升级三连** | 三个递进的压力事件 | 长篇章节 |
| **假高潮** | 读者以为危机解决了，但没完 | 反转 |
| **静态时间** | 重大事件前，突然安静下来 | 蓄力 |

## 作者信号转译

当用户说"按某作家风格"，按以下方式转译为技法组合，而非直接模仿。

| 用户请求 | 转译结果 |
|---------|---------|
| 按东野圭吾风格 | 有限视角+延迟揭示+日常细节里的诡计+结尾反转+道德困境 |
| 按村上春树风格 | 第一人称+日常与超现实的混合+孤独感+细节描写+开放式结尾 |
| 按张爱玲风格 | 感官细节+心理博弈+欲望与现实的裂痕+城市空间描写+苍凉余味 |
| 按经典武侠风格 | 快节奏对话+场景动作描写+人物关系的戏剧性+命运感+侠义与私欲的冲突 |
| 按刘慈欣风格 | 设定驱动+宏大尺度+科学细节的戏剧化+文明困境+冷淡叙事下的情感 |
| 按网文爽文风格 | 强主角+金手指+打脸节奏+升级感+情绪释放+卡点结尾 |
| 按经典悬疑风格 | 信息不对称+时间压力+所有安全选项逐一消失+结尾留一扇暗门 |

**规则**：不复刻具体作者独特的表达、角色名、标志性场景或台词。仅使用可泛化的技法组合。
