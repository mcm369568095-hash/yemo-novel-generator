# 多线交织 · 阶梯角色网络与暗线×暗线（三维命运网设计法）

> 定位：根基四文档（写什么）+ 梯度（垂直纵深，world-gradient.md）+ 暗线（水平密网，plot-threads.md）三者正交，但**读者的史诗感来自第三维——线动起来互相撞**。本文把"每个梯度层 = 新社会版图"与"主线×暗线、暗线×暗线交织"落成可执行的登记表与铁律。
> 工作范例（已落地可照搬）：《示例项目》五卷·每层新朋友/新敌人 + 暗线A×B×C×D 交叉表。

## 总纲：一张网，立成一座会呼吸的城

```
         超验层 ── 新存在/新敌（飞升接口）
         大陆层 ── 新盟友/新敌（隐族）
         宏观层 ── 新世家/新敌（皇朝）
         中观层 ── 新官/新敌（大城）
微观层(主角)┄┄ 新挚友/新敌（豪族）
   │
 主线 × 暗线A×B×C×D ── 在每层"逻辑交汇点"撞出小高潮
 暗线 × 暗线(A×B / A×C / B×C / D×A) ── 在交叉点撞出更大爆点
```

- 梯度给"垂直台阶"：每层不是空场景，是**新的社交生态**，必有新挚友、新敌人、可能一个中立关键人。
- 暗线给"水平密网"：但暗线之间**不是平行不交的河**——它们互相穿越，在交叉点炸出比单线交汇更猛的爆点。
- 两者正交，再叠加"线间互撞"，才是真·史诗架构。

## 一、阶梯角色网络（每层 = 新社会版图）

铁律：
1. **每层须引入 ≥1 新挚友/盟友 + ≥1 新敌人/对手（+ 可含 1 中立关键人）**。新角色不能是"路人甲"，须带【暗线】字段（回 plot-threads 规则）。
2. **新角色须嵌进同源分流谱系 / 梯度阶层**：力量、阵营、目的都能在世界观里溯源（呼应根基一、world-gradient），不成黑洞。
3. **旧角色在新层的"位置迁移"也要写**：如二房沈鹤年卷三进到皇朝层，从"夺嫡死敌"变成"被血魂殿胁迫的棋子"，身份随层升级。
4. **新朋友 ≠ 工具人**：每人有自己的得失顶点，目标与主角不同；新敌人须有"为何盯上主角"的因果（回 world-gradient 因果降维，禁巧合）。

## 二、主线 × 暗线 交织矩阵

每卷建一张矩阵：行 = 线（主线 + 各暗线），列 = 卷，格 = 交汇事件 + 产出小高潮。使"谁在哪卷、哪章、撞出什么"一目了然。范例见示例作品初级大纲·「每卷交织矩阵」。

## 三、暗线 × 暗线 交织（暗线互撞 · 史诗级）

暗线之间会**互相穿越**，交叉点产出比单线交汇更猛的爆点。三类交叉：

- **信息互补型**：A 知 X、B 知 Y，合流揭 Z。例：沈彻知"源脉密钥真相"，苏晚知"罗盘指向"，合流揭同源分流真相。
- **目标冲突型**：A 要护主、B 要复仇，撞出张力。例：苏晚要杀二房（灭族仇），主角要保二房结盟抗外敌，张力爆表。
- **身份重叠型**：A 的仇人 = B 的恩人，或 A 与 B 早有默契。例：沈彻与福伯早有暗卫默契，卷四合流；二房与城主赵莽同被血魂殿控，从互算到同病相怜。

设计工具：**暗线交叉登记表**（哪两条线 × 第几章 × 因何交叉 × 产出什么小高潮/反转）。每条暗线须在**至少一处**与其他暗线交叉，避免"各行其是"。

## 四、× 根基四文档 / 梯度 / 暗线 对接

- **根基二 初级大纲**：每卷须含 **①本卷梯度层 ②本卷新角色网络（新挚友/新敌/中立）③主线×暗线交织矩阵 ④暗线×暗线交叉表**。
- **根基三 角色库**：每张卡含【所属阶梯层】【暗线】【暗线交叉（与哪些暗线在哪卷交叉、产出什么）】。
- **根基一 世界构建**：须含"每层新社会版图"小节，列明每层将登场的新势力/新人物归属。
- 与 world-gradient 正交：本文管"每层的社会生态 + 线间互撞"；world-gradient 管"层级的垂直纵深"。
- 与 plot-threads 正交：本文把 plot-threads 的单线交汇升级为"多线互撞网络"。
