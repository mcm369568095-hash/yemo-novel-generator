# 用户 Intake 问卷（技能分发统一入口）

> 用途：任何人拿到本技能（fork 后），先用这份问卷完成"立项"。问卷答案会**自动映射**到根基文档与风格引擎，技能据此生成 `世界构建/初级大纲/角色库` 三文档 + 选定风格包，再进入写作。
> 用法：把下列 7 个模块抛给用户（可用 AskUserQuestion 或自然语言收集）。带 ⭐ 的为必答；"上传"类为可选项，上传后技能做**文风抽取**而非照搬。

---

## 模块 1 · 书名与根命题 ⭐
- 问题：小说叫什么？一句话说清"它讲一个关于____的世界"？
- 映射：→ 根基一 根命题反推（见 four-pillars-spine.md 根基一规则1）
- 例：「示例项目」→ 根命题=血脉为王，但血脉从何而来。

## 模块 2 · 世界观类型 + 终极秘密 ⭐
- 问题：选一种世界观基底，并说出"这本书最终要揭开的那个真相/主角最终要抵达的目标"是什么？
  - 选项：血脉至上 / 末世求生 / 都市异能 / 古典仙侠 / 科幻星际 / 历史架空 / 悬疑诡秘 / 其他（自填）
  - 终极秘密填空：这本书的"永生之门/彼岸/终极"是______？
- 映射：→ 根基一 规则2/3/4（终极秘密 + 同源分流 + 主题升华）
- 注意：若用户说不清终极秘密，技能须**主动给 3 个候选**（对标盗墓/阳神/永生），让用户挑，不可跳过。

## 模块 3 · 目标风格包 / 上传文风 ⭐
- 问题：想要什么"文风质感"？
  - 选项（见 `styles/STYLE-INDEX.md`）：默认平衡(yemo) / 梦入神机密度 / 烽火抒情 / 猫腻智性 / 诡秘克苏鲁 / 其他
  - **或上传**：贴一段你喜欢的原文（≥300字），技能做文风抽取 → 生成临时风格包 `styles/_custom_<项目>.md`
- 映射：→ 风格层（prose-quality + cool-points + technique 覆盖）+ Hook 9 技法选择
- 关键：用户上传的文风**只抽技法，不抄文本、不模仿在世作者**（守原边界）。

## 模块 4 · 篇幅与卷数目标 ⭐
- 问题：大概写多长？
  - 选项：短篇(<1万) / 中小篇(1–5万) / 中篇(5–15万) / 长篇(15–60万) / 超长篇(60万+，如300章)
- 映射：→ 根基二 初纲卷数（短篇可压缩为"单弧光"，长篇拆五卷弧光）

## 模块 5 · 角色初设 ⭐
- 问题：主角/关键反派有没有雏形？
  - 选项A：从零生成（技能按根命题造主角弧光 + 反派）
  - 选项B：我提供（贴人物设定，技能转成角色库人设卡）
- 映射：→ 根基三 角色库（人设卡模板）+ Hook 3 边界卡

## 模块 6 · 红线与忌讳
- 问题：有什么绝对不能写/必须写的？（如：禁突然话多、禁章末感慨、禁女主谈恋爱、必须每章有打脸）
- 映射：→ Hook 12 红线检查 + 根基四 写前清单（用户红线并入门禁）

## 模块 7 · 读者定位
- 问题：主要给谁看？
  - 选项：全年龄广谱 / 男频爽文读者 / 女频情感读者 / 严肃文学向
- 映射：→ 根基四 读者视角检查强度（全年龄→古词必解释、零背景可读；严肃向→可适当留白）

---

## 立项产出（问卷收齐后技能自动生成）

```
<项目目录>/
├── 世界构建_<书名>.md     ← 模块1+2
├── 初级大纲_<书名>.md     ← 模块2+4
├── 角色库_<书名>.md       ← 模块5
├── 红线_忌讳.md           ← 模块6（并入门禁）
└── styles/_active.md      ← 模块3（软链/复制选定风格包）
```
生成后进入七步单章循环（消费上述文档）。

> **分发提示**：fork 本技能后，把这份问卷当"新用户引导"；不同项目填不同答案即可生成完全不同的小说——这就是"一套引擎，多种内容"的分发内核。
