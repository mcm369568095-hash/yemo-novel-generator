# 梯度世界观与预埋暗线（势力阶梯设计法）

> 定位：根基四文档（尤其根基一世界观）之上，再加一道"垂直维度"——**势力梯度阶梯**。水平方向靠暗线（plot-threads.md）织密，垂直方向靠梯度立纵深。两者正交，合起来才是史诗架构。
> 工作范例（已落地可照搬）：《示例项目》沈彻被隐族带走（因地脉觉醒）的梯度根因链。

## 总纲：你的世界该是一座塔，不是一张平面图

读者永远知道"上面还有一层"，好奇心就有燃料。

```
        超验层（飞升/科幻预留）
              ↓ 终极秘密的尽头
        大陆/世界层（超级势力·隐族）
              ↓
        宏观层（国家·世家·皇族）
              ↓
        中观层（大城·州郡）
              ↓
        微观层（城·豪族 ← 主角起步）
```

## 一、为什么"梯度"是史诗级技巧

1. **信息梯度 = 好奇心燃料**：每揭一层，上一层还在阴影里 → 无限钩子。这是"cosmological verticality"（多部经典长篇共用的同款手法）。
2. **预埋 = 伏笔的时间复利**：高阶层对主角的影响"早就埋在低阶层"。高阶层揭晓时，读者回头咂摸，所有早出现的细节串成闭环。
3. **助力合理性（杜绝机械降神）**：高阶层给主角的帮助，必须能顺着阶梯"因果降维"到主角当下能接触的低阶层事件。
4. **梯度揭示 = 卷级弧光的天然骨架**：每卷"升一层阶"，五卷自动有节奏，与根基二弧光同构。

## 二、阶梯模板（可裁剪 / 可扩展）

通用五层（玄幻 / 都市 / 悬疑 / 科幻都可用）：

- **微观层（当前舞台）**：主角所在小环境（城·豪族 / 街区 / 班级）。
- **中观层**：更大的行政区划 / 势力（大城 / 郡国 / 公司总部）。
- **宏观层**：国家 / 王朝层面（世家 / 皇族 / 政府）。
- **大陆/世界层**：超级势力、隐族、跨域敌人。
- **超验层（飞升/科幻预留）**：人间 → 过渡地 → 仙境 → 神境 → 无上境（科幻对应：行星 → 星系 → 维度）。

- **揭示铁律**：当前卷只在"当前层 + 上一层(传闻) + 再上一层(影子)"活动；更高层只以"名词 / 物件 / 谣言"存在（预埋素材）。

## 三、揭示节奏表（梯度 × 卷）

任一时刻，世界里只有"三层"在故事里：

| 状态 | 含义 | 存在形式 |
|---|---|---|
| active | 当层，主角当前厮杀的舞台 | 完整描写 |
| hinted | 上一层，传闻中的更大势力 | 人名 / 事件 / 压力 |
| shadow | 再上一层，神秘的影子 | 一个名词 / 异物 / 异象 |

- 每升一卷，原 shadow 转正为 hinted，原 hinted 转正为 active。始终保持"上有悬念"。
- **飞升层处理**：当前五卷在人间层，但终极秘密须指向超验层（"血脉稀释之枷"通向天外天），只埋"天外有天"的名词，不展开——为续作留接口。

## 四、预埋纪律（梯度法的灵魂）

1. **锚点早埋**：每个高阶层，须在第一~二卷就有"可见信号"（一件异物、一个外来人名、一句传闻、一处异常天象），且该信号后来可回溯解释。
2. **因果降维闭环**：高阶层对主角的影响，必须能追到一条"低阶层具体事件链"。例：隐族降临 → 因为地脉觉醒 → 地脉在主角城池底下 → 第1章玉坠发烫就是这个信号。链不能断。
3. **助力授权**：任何高阶层人物给主角的帮助，须经由预埋的因果链接获得授权（父被隐族带走 → 在隐族学到真相 → 归来带资源）。禁止"天降贵人"。
4. **暗线增殖登记表**：每多一层，暗线翻倍。须建"暗线登记表"（人物 × 阶层 × 交汇卷 × 锚点章节），防止失控（呼应 plot-threads.md 逻辑铁律）。
5. **每层 = 新社会版图（阶梯角色网络）**：每个梯度层不只是场景，是新的社交生态——须引入 ≥1 新挚友/盟友 + ≥1 新敌人/对手（+ 可含 1 中立关键人）。旧角色进新层时"位置"也要迁移（如二房卷三从夺嫡死敌变被胁迫棋子）。新角色须在世界观可溯源。完整法则与"暗线×暗线交织"见 `references/thread-weave.md`。

## 五、暗线嵌套（用梯度生暗线）

以"父亲被隐族带走"为标杆案例：

- **根因链**：地脉觉醒(根因) → 隐族降临临渊城(因地脉) → 相中沈彻(第37任宿主能听脉) → 带走/假死(父暗线A根) → 沈彻在隐族得知三重真相(枯潮/血魂殿/超脱枷) → 归来助子(带隐族资源)。
- 链每一环都是"逻辑必要性"，故父的归来不是运气，是必然。
- **次级暗线繁衍**：隐族内部有派系(带走沈彻的一派 vs 反对派) → 卷四隐族内乱成新爆点；地脉觉醒还引动其他豪族觊觎临渊城 → 旁支暗线。
- 这就是用户说的："前期都预埋好，看着才震撼，才是逻辑的完整闭环。"

## 六、× 根基四文档对接

- **根基一**：梯度阶梯写进世界构建文档（"势力梯度阶梯"小节）；终极秘密须贯穿所有阶层（最高层才是秘密尽头）。
- **根基二**：每卷加"梯度揭示表"，标注本卷 active / hinted / shadow 阶层。
- **根基三**：高阶层人物（如隐族使者）也要建卡，其【暗线】写明"来自哪层、为何降临、与主角因果链接"。
- 与 plot-threads.md（水平暗线）正交：本文管"垂直阶层"，plot-threads 管"水平交织"，二者共同构成网。
