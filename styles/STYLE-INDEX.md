# 风格包注册表（Style Packs）

> 风格包 = 一套**可插拔的文风预设**，覆盖 yemo 引擎的 `prose-quality.md` + `cool-points.md` + `technique-matrix.md` 三处。切换风格包 = 切换小说质感，引擎其余部分（根基四文档/边界卡/门禁）不变。
> 这正是"一套引擎、多种内容"的扩展内核：用户上传任意文风，抽成包即可生成同构异质的小说。

---

## 一个风格包长什么样（格式）

```
styles/<pack-id>.md
├── id / name / 来源（如"梦入神机密度·技法转译，非模仿"）
├── 文笔覆盖(prose-overrides)：覆盖 prose-quality.md 的哪些纪律、放宽/收紧哪些
├── 爽点覆盖(cool-overrides)：覆盖 cool-points.md 的脉冲密度/打脸节奏
├── 技法集(techniques)：默认启用的技法引擎 id 列表
├── 术语容忍(terminology)：古词/黑话的处理强度（必解释 / 可留白）
├── 示例 prose：2–3 段样板，供生成时对齐质感
└── 禁忌：本风格下绝对不能出现的写法
```

## 如何新增一个风格包（三步）

1. 在 `styles/` 下新建 `<pack-id>.md`，按上格式填。
2. 在本文档"已内置包/预留"表登记一行。
3. 若由上传文风生成，命名 `_custom_<项目>.md`，并在 `user-intake.md` 模块3 注明来源（守"只抽技法不抄文本"边界）。

> 风格包**不携带剧情、不携带世界观**——那归根基文档管。风格包只管"怎么写"，根基文档管"写什么"。职责分离，才能任意组合。
